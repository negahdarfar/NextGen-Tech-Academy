Privacy Policy

Effective date: 20 November 2026

NextGen Tech Academy is a personal software project for preparing technology and educational documentary videos. This policy explains how information is handled when the project is configured by its owner.

Google and YouTube data

If the owner connects a Google account, the project may receive OAuth authorization to upload videos to the owner's YouTube channel. The project uses that authorization only for the YouTube actions explicitly configured by the owner. It does not sell Google user data, use it for advertising, or use it to build profiles about users.

Storage and security

OAuth credentials and API keys configured by the owner are intended to be stored as private GitHub Actions repository secrets and used by the corresponding workflow. They should never be committed to source code or shared publicly. Video files, workflow logs and generated artifacts may be stored by GitHub according to the repository and GitHub Actions retention settings.

Sharing

The project does not intentionally sell or share Google user data with data brokers or advertisers. Third-party infrastructure providers (such as GitHub and any content or AI providers deliberately configured by the owner) process information as needed to provide their services and are governed by their own terms and privacy policies.

Retention and revocation

The owner can remove configured credentials from GitHub repository secrets and revoke the application's access from the Google Account security settings. Copies of workflow artifacts and logs may remain until their configured retention period expires or they are deleted.

Children

This project is not designed to collect personal information from children.

Contact

For questions about this project or this policy, use the project repository: github.com/negahdarfar/NextGen-Tech-Academy.
